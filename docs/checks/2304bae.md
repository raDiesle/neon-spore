## `2304bae` — three named groups instead of one row

> on the SHAPES page, can you tell what can be combined with what without being told?

- **subject** the control row at the top of the SHAPES tab, above the cards — the one that picks a skin, a motion and whether the key light is on
- **changed** the row used to be sixty-odd buttons in a straight line, split only by a one-letter tag (`SKIN`, `·`, `MOTION`) set in the same small type as the buttons themselves — nothing told you that a skin, a motion and the light are three separate choices that all combine freely, or what the plain buttons `OWN` and `LIT` actually meant; that lived only in a tooltip you had to hover. The row is now three named groups — SKIN, MOTION, LIGHT — each with its own heading and, under it, one line saying in words what it picks, that it does not touch the other two, and which one is currently picked (for example "Now: membrane" or "Now: OWN")
- **decide** look at the row without hovering anything: can you tell that a skin, a motion and the light are three independent choices, that any combination of them is fine, and which one of each is currently picked — including whether the motion is on OWN and whether the light is on?
- **before** one unbroken row of buttons under three short tags, with `OWN` and `LIT`'s meaning available only by hovering
- **after** three headed groups (SKIN, MOTION, LIGHT), each with a line of its own stating what it does and its current pick
- **where** `bun run dev` (or `bun run preview`) → NOT BUILT YET → SHAPES, the row above DRAFTS
