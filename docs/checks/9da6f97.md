## `9da6f97` — the authored card

> set one wave to teach a card it did not used to, and play from the start — does that card come up on that wave and nowhere else

- **badge** implementation
- **subject** which card a wave opens on the first time it teaches something
- **changed** a wave may now author `card` to pick which subject it raises, overriding the derivation from what it actually contains, and it reaches real play — not just the director's tooling — through `startWave`
- **decide** authoring a card on a wave — does the right card come up there and does the wave it used to come from stay silent?
- **before** nothing, this is new
- **after** an author can put a teaching moment on a chosen wave instead of always the first one that happens to carry it, and it holds when the wave is actually played
- **where** `tools/director`, the CARD select beside CONTROL SET; `bun run preview`, the wave whose card changed, played from a fresh pair
