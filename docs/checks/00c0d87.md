## `00c0d87` — the control set picker

> looking at a wave in the editor, can you tell which controls the pair will have without starting it?

- **badge** implementation
- **subject** the control set picker in the WAVE tab, and its wave-list mark
- **changed** `wave.controls` had no way to be set from the editor; the WAVE tab now carries a picker and a wave-list mark for a non-default set
- **decide** does the picker's value and the wave-list mark agree with what CONTROL SETS shows for this wave, without opening the panel or starting a run?
- **before** no field in the editor could name a control set
- **after** a WAVE-tab select, a ⎈ list mark, and a CONTROL SETS page per panel
- **where** director → WAVE tab; director → ⎈ CONTROL SETS
