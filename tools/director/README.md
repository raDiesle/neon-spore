# Director Mode — not built yet

Pick a wave, spawn a single creature, speed 0–300 %, single step, show the
beat, show hitboxes, simulate latency and packet loss, record.

It is not only your tool. It is the surface through which an agent reproduces a
state on purpose instead of describing it. **The recording format is the replay
test format** — what you play by hand becomes a test case
(`packages/sim/src/replay.ts`).

Build it after the port, before the content work.
